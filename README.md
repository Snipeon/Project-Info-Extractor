# Project-Info-Extractor
A project I did for CFC. A basic bash script to extract info about a user's device.

The script, as mentioned, uses bash. 
It firstly prompts for user confirmation to run the script.
Then it grabs the public and internal IP addresses, a censored(?) version of the device MAC address, 
top 5 processes using the most CPU, memory and swapfile stats, active services, and top 10 largest files in /home.

Simple lil' script.
